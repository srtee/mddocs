    A Complete Constant Potential Simulation

    TipIn this section
    • Step-by-step construction of an electrode-electrolyte input script
    • Physical meaning of each section with justification
    • Expected output and how to interpret it
    • Post-processing for common observables (capacitance, density profiles, potential)

    What We Are Building

    A planar electrode supercapacitor with: - Two gold electrodes (top and bottom) - SPC/E water with 1M NaCl electrolyte - Constant potential mode (1 V difference) - NVT ensemble at 300 K

    Goal: By the end, you should understand every line of this input and know how to modify it for your own system.

    Step 1: Initialization

    units metal
atom_style charge
boundary p p f

    Physical meaning:

    Command Physical Meaning Why
    units metal Å, eV, ps Standard for materials; electrode parameters usually in eV
    atom_style charge Each atom has charge Required for electrostatics; no bonds needed for simple electrolytes
    boundary p p f Slab geometry Two electrode surfaces; vacuum region above electrolyte

    Why not units real? Many electrode force field parameters are published in eV (metal units). Using units real would require converting kcal/mol to eV (factor of 23.06). If your parameters are in kcal/mol, use units real.

    Step 2: Create the Box and Atoms

    variable Lx equal 20
variable Ly equal 20
variable Lz equal 60

region box block 0 $Lx 0 $Ly 0 $Lz
create_box 5 box    # 1=bot electrode, 2=top, 3=O, 4=H, 5=Na, 6=Cl

    Box dimensions: 20×20×60 Å = 24,000 Å³ For water at 1 g/cm³, this holds ~480 water molecules (the electrolyte region is 20×20×50 Å = 20,000 Å³).

    # Define regions
region bot block 0 $Lx 0 $Ly 0 5
region top block 0 $Lx 0 $Ly 55 $Lz
region elyte block 0 $Lx 0 $Ly 5 55

# Create atoms
create_atoms 1 region bot    # bottom electrode (type 1)
create_atoms 2 region top    # top electrode (type 2)
# Water and ions: use moltemplate, packmol, or convert from structure file

    Physical meaning of regions:

    Region Size Purpose Atom Count (estimate)
    box 20×20×60 Å Full simulation cell —
    bot 20×20×5 Å Bottom electrode ~200 Au atoms
    top 20×20×5 Å Top electrode ~200 Au atoms
    elyte 20×20×50 Å Water + ions between ~480 water + 10 Na + 10 Cl

    Why 50 Å gap? The electrode separation should be large enough that periodic images in x,y don’t interact through the electrolyte. For 1M salt, Debye length ≈ 10 Å, so 50 Å is sufficient.

    # Define groups
group bot region bot
group top region top
group elyte region elyte
group electrode union bot top
group mobile subtract all electrode    # electrolyte only

    Step 3: Force Field

    pair_style lj/cut/coul/long 10.0

    Why lj/cut/coul/long? We need: - LJ for short-range repulsion/attraction - Coulomb for ionic interactions - long suffix = long-range handled by kspace (pppm/electrode)

    Electrode Parameters

    # Electrode-electrode (soft repulsion, no chemical bonding)
pair_coeff 1 1 0.01 3.0    # ε=0.01 eV, σ=3.0 Å (soft repulsion)
pair_coeff 2 2 0.01 3.0    # same for top
pair_coeff 1 2 0.005 3.0   # cross-term (smaller)

    Why ε=0.01 eV? This is a soft repulsion that prevents electrolyte atoms from penetrating the electrode. Real metallic bonding is much stronger but is not modeled (CPM handles charge response instead).

    Why σ=3.0 Å? Approximately matches Au atomic radius. The electrode atoms are just “soft spheres” preventing overlap.

    Electrolyte Parameters

    # Water LJ (SPC/E)
pair_coeff 3 3 0.155 3.166    # O: ε=0.155 eV, σ=3.166 Å
pair_coeff 4 4 0.0 0.0        # H: no LJ (charged but no van der Waals)

# Ion LJ (Joung & Cheatham for SPC/E)
pair_coeff 5 5 0.0874 3.40    # Na: ε=0.0874 eV, σ=3.40 Å
pair_coeff 6 6 0.100 4.45      # Cl: ε=0.100 eV, σ=4.45 Å

    Cross-Terms

    # Electrode-water
pair_coeff 1 3 0.005 3.1    # bot-O: mixed using Lorentz-Berthelot
pair_coeff 2 3 0.005 3.1    # top-O: same
pair_coeff 1 4 0.0 0.0      # bot-H: no LJ
pair_coeff 2 4 0.0 0.0      # top-H: no LJ

# Ion-water (important for solvation)
pair_coeff 5 3 0.114 3.28    # Na-O
pair_coeff 6 3 0.124 3.81    # Cl-O
pair_coeff 5 4 0.0 0.0       # Na-H: no LJ
pair_coeff 6 4 0.0 0.0       # Cl-H: no LJ

# Ion-electrode
pair_coeff 1 5 0.005 3.2    # bot-Na
pair_coeff 2 5 0.005 3.2    # top-Na
pair_coeff 1 6 0.005 3.7    # bot-Cl
pair_coeff 2 6 0.005 3.7    # top-Cl

# Ion-ion
pair_coeff 5 6 0.0935 3.925  # Na-Cl (Lorentz-Berthelot)
    WarningMissing Pair Coefficients

    All unique atom type pairs must be defined. LAMMPS will error if any pair is missing. Use * for wildcards: pair_coeff * 4 0.0 0.0 means “all types with type 4 have zero LJ”.

    Kspace Setup

    kspace_style pppm/electrode 1e-5
kspace_modify slab 3

    Why pppm/electrode? Standard pppm doesn’t provide the electrode-electrode interaction matrix that ELECTRODE needs.

    Why slab 3? Non-periodic z requires the 2D Ewald correction. The 3 means the third dimension (z) is non-periodic.

    Step 4: Apply the ELECTRODE Fix

    fix fxconp bot electrode/conp -1.0 1.805 couple top 1.0 symm on

    What each argument means:

    Argument Value Meaning
    bot group Apply to bottom electrode
    -1.0 potential (V) Bottom electrode held at -1 V
    1.805 eta (Å⁻¹) Gaussian smearing width
    couple top 1.0 couple Top electrode at +1 V
    symm on — Total electrode charge = 0

    Why symm on? For a symmetric capacitor, the total charge must be zero. With symm on, if bot has charge -Q, top automatically has +Q.

    The eta value (1.805 Å⁻¹): This is the standard value for metallic electrodes. It determines how the electrode charge is distributed — larger eta = narrower distribution (more like point charge).

    Dynamic Potential Control

    # Linear sweep (cyclic voltammetry simulation)
variable V equal ramp(-1.0, 1.0)
fix fxconp bot electrode/conp v_V 1.805 couple top 1.0
    # Sinusoidal (AC impedance simulation)
variable V equal "2.0 * sin(time * 0.01)"
fix fxconp bot electrode/conp v_V 1.805

    Step 5: Integrators

    fix frozen all nve
fix mytemp elyte langevin 300.0 300.0 100.0 12345

    Physical meaning:

    Fix What It Does Why
    fix frozen all nve No dynamics on frozen atoms Electrodes are static
    fix mytemp elyte langevin Langevin thermostat Controls T; ergodicity

    Why Langevin? For electrode-electrolyte systems, Langevin is often preferred because: 1. It handles heterogeneous dynamics well (electrolyte may have slow ions) 2. Stochastic term helps escape metastable states 3. No “ghost” forces from thermostat coupling

    Damping time of 100 fs: This is appropriate for water at 300 K. Too small = over-damped; too large = slow equipartition.

    For Mobile Electrodes

    fix elec_nvt electrode nvt temp 300.0 300.0 100.0
fix elyte_nvt elyte nvt temp 300.0 300.0 100.0

    Or with Langevin on both:

    fix elec_langevin electrode langevin 300.0 300.0 100.0 12345
fix elyte_langevin elyte langevin 300.0 300.0 100.0 54321

    Step 6: Energy Minimization

    minimize 1e-6 1e-9 1000 10000

    Why: Before dynamics, the system has atomic overlaps and bad contacts. Minimization: - Applies conjugate gradient or steepest descent - Reduces forces to acceptable level - Prevents “blow up” in first dynamics steps

    Parameters: - 1e-6 = force tolerance (forces < this are considered converged) - 1e-9 = energy tolerance - 1000 = max iterations - 10000 = max force evaluations

    What to expect: You should see energy decrease over many iterations. If it doesn’t converge, check for: - Overlapping atoms - Missing pair coefficients - Invalid geometry

    Step 7: Output Configuration

    thermo 100
thermo_style custom step temp pe ke vol density f_fxconp[1] f_fxconp[2] f_fxconp[3] f_fxconp[5] f_fxconp[6]

    What each output column means:

    Column Meaning Expected
    step Timestep number Increases by 100
    temp Temperature 300 ± 15 K
    pe Potential energy Negative; stable
    ke Kinetic energy Fluctuates with T
    vol Volume Constant (NVT)
    density Mass/volume ~1.0 g/cm³ for water
    f_fxconp[1] Electrode fix energy ~0, small fluctuations
    f_fxconp[2] Bottom electrode potential Should be -1.0 V (convergence check)
    f_fxconp[3] Top electrode potential Should be +1.0 V
    f_fxconp[5] Bottom electrode charge Negative; magnitude depends on capacitance
    f_fxconp[6] Top electrode charge Positive; = -Q_bot

    Trajectory Output

    dump 1 all custom 100 traj.lammpstrj id type x y z q
dump 2 all dcd 100 traj.dcd    # binary format; smaller

    For large trajectories: Use DCD format (10-100× smaller). For analysis, read with MDAnalysis or mdtraj.

    Step 8: Run

    run 10000

    At 1 fs timestep: 10 ps simulation At 2 fs timestep: 20 ps simulation

    Simulation time needed for different properties:

    Property Time Scale Why
    Minimization < 1 ps Remove bad contacts
    Equilibration 100–500 ps System reaches steady state
    Double-layer formation 100–500 ps Ions redistribute near electrodes
    Diffusion (MSD) 1–10 ns Statistical accuracy for D
    Capacitance (steady) 1–10 ns Need averaged Q at each V
    Capacitance (frequency) 10–100 ns For AC response

    Expected Output: What to Look For

    Energy Conservation

    In a well-behaved simulation: - TotEng should drift < 0.1% over 10 ps - f_fxconp[1] should fluctuate around constant

    How to check: After running, plot TotEng vs step in the log file. If it increases monotonically: - Timestep too large → reduce to 0.5 or 1 fs - Cutoff too small → increase to 12 Å - Atoms overlapping → re-minimize

    Electrode Charges

    variable Q_bot equal f_fxconp[5]
variable Q_top equal f_fxconp[6]
fix printQ all print 100 "Q_bot = $(v_Q_bot) Q_top = $(v_Q_top)" file charge_vs_time.txt

    The charges should: 1. Start at initial guess (based on zero voltage) 2. Equilibrate within 10–100 ps 3. Fluctuate around equilibrium (thermal noise)

    Charge magnitude: For a 20×20 Å electrode at 1 V in 1M NaCl: - Capacitance ≈ 10 μF/cm² - Electrode area = 400 Å² = 4×10⁻¹⁴ m² - Q = C × V = 10×10⁻⁶ × 4×10⁻¹⁴ × 1 = 4×10⁻¹⁹ C = 2.5 e - Expect |Q_bot| ≈ 2–5 electrons worth of charge

    Capacitance Calculation

    For a symmetric two-electrode system:

    # Run at V = 0.5 V
fix fxconp bot electrode/conp -0.25 1.805 couple top 0.25 symm on
run 10000
variable Q_05V equal f_fxconp[5]

# Run at V = 1.5 V  
# (change potential and run again)
variable Q_15V equal f_fxconp[5]

# Capacitance = dQ/dV ≈ (Q_15V - Q_05V) / (1.5 - 0.5)

    For more accuracy, use multiple voltages and fit the Q-V curve.

    Complete Input Script

    # ============================================
# Constant Potential Supercapacitor
# Au electrodes, SPC/E water, 1M NaCl
# ============================================

units metal
atom_style charge
boundary p p f

# --- Variables ---
variable Lx equal 20
variable Ly equal 20
variable Lz equal 60

# --- Box ---
region box block 0 $Lx 0 $Ly 0 $Lz
create_box 6 box    # 1=bot Au, 2=top Au, 3=O, 4=H, 5=Na, 6=Cl

# --- Regions ---
region bot block 0 $Lx 0 $Ly 0 5
region top block 0 $Lx 0 $Ly 55 $Lz
region elyte block 0 $Lx 0 $Ly 5 55

# --- Electrode atoms ---
create_atoms 1 region bot
create_atoms 2 region top

# --- Electrolyte (pre-generated positions recommended) ---
# For this example, assuming water/ions already placed

# --- Groups ---
group bot region bot
group top region top
group elyte region elyte
group electrode union bot top
group mobile subtract all electrode

# --- Force field ---
pair_style lj/cut/coul/long 10.0

# Electrode-electrode
pair_coeff 1 1 0.01 3.0
pair_coeff 2 2 0.01 3.0
pair_coeff 1 2 0.005 3.0

# Water (SPC/E)
pair_coeff 3 3 0.155 3.166    # O
pair_coeff 4 4 0.0 0.0        # H

# Ions
pair_coeff 5 5 0.0874 3.40    # Na
pair_coeff 6 6 0.100 4.45     # Cl

# Cross terms
pair_coeff 1 3 0.005 3.1
pair_coeff 2 3 0.005 3.1
pair_coeff 1 4 0.0 0.0
pair_coeff 2 4 0.0 0.0
pair_coeff 5 3 0.114 3.28
pair_coeff 6 3 0.124 3.81
pair_coeff 5 4 0.0 0.0
pair_coeff 6 4 0.0 0.0
pair_coeff 1 5 0.005 3.2
pair_coeff 2 5 0.005 3.2
pair_coeff 1 6 0.005 3.7
pair_coeff 2 6 0.005 3.7
pair_coeff 5 6 0.0935 3.925

kspace_style pppm/electrode 1e-5
kspace_modify slab 3

# --- ELECTRODE fix ---
fix fxconp bot electrode/conp -1.0 1.805 couple top 1.0 symm on

# --- Integrators ---
fix frozen all nve
fix mytemp elyte langevin 300.0 300.0 100.0 12345

# --- Output ---
thermo 100
thermo_style custom step temp pe ke vol density f_fxconp[1] f_fxconp[2] f_fxconp[3] f_fxconp[5] f_fxconp[6]

variable Q_bot equal f_fxconp[5]
variable Q_top equal f_fxconp[6]
fix printQ all print 100 "Q_bot = $(v_Q_bot) Q_top = $(v_Q_top)"

dump 1 all custom 100 traj.lammpstrj id type x y z q
dump 2 all dcd 100 traj.dcd

# --- Run ---
minimize 1e-6 1e-9 1000 10000
run 10000
